# SCRE Design System

Biblioteca de componentes de interfaz de usuario (UI) para React, construida a partir de un sistema de diseño de Figma. Este paquete proporciona componentes reutilizables, escalables y consistentes para acelerar el desarrollo de interfaces.

## Instalación

Puedes instalar la biblioteca en tu proyecto de React utilizando npm:

```bash
npm install scre-design-system
